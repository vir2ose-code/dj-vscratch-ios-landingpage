# DJ V-SCRATCH LIVE Studio – iOS & iPadOS

Official product landing page and support hub for **DJ V-SCRATCH LIVE Studio**, developed by **vir2oseSOUND** (Waldemar Krucinski).

## Overview
This repository hosts the static landing page, documentation, and support resources for the Apple App Store release of DJ V-SCRATCH LIVE Studio for iPhone and iPad.

- **Platform:** iOS & iPadOS
- **Engine:** C++ / JUCE DSP Core
- **Business Model:** Fair One-Time Purchase (No Subscription)
- **Official Domain:** https://ios.waldemar-krucinski.com

## Key Features
- **Ultra-Low Latency Engine:** Optimized CoreAudio integration for accurate vinyl emulation and scratching.
- **Multitouch Turntablism:** Responsive virtual platters and customizable crossfader curve.
- **V-Chopper & Performance Pads:** On-the-fly cue triggering, loop slicing, and beat juggling.
- **Hardware Integration:** Class-compliant USB audio interface and MIDI controller ready.
